# 💍 Engagement Invitation Website — Free Template

A beautiful, animated and fully customizable digital engagement invitation website. Built with pure HTML, CSS and JavaScript — no framework needed.

> 🤍 This project was originally built for my brother's engagement ceremony as a personal gift. It is completely non-commercial, free to use, and open to any kind of development or customization.
> 
> 🤖 AI assistance was used during the development of this project.

## ✨ Features

- Animated flower garden entrance screen with butterflies & birds
- Falling petals animation
- Scroll-reveal sections
- 3D photo gallery stack
- Scratch card to reveal the date
- Live countdown timer
- Add to calendar button (.ics)
- Venue section with Google Maps integration
- Share via WhatsApp & copy link
- Background music player
- Guest photo upload via Google Forms
- QR code table screen for event day
- Mobile responsive design
- Wax seal & ribbon envelope animation
- Gold & cream elegant theme

## 🛠️ Technologies Used

- HTML5
- CSS3 (animations, transitions)
- JavaScript (vanilla)
- GSAP (ScrollTrigger animations)
- Canvas API (scratch card)
- Firebase Hosting (optional)

## 🔧 How to Customize

Open the files and replace all placeholder values:

| Placeholder | Description |
|---|---|
| `[İSİM_1]` / `[İSİM_2]` | Names of the couple |
| `[DAVET_KODU]` | URL access code |
| `[TARİH]` | Event date |
| `[GÜN]` / `[AY]` / `[YIL]` | Day / Month / Year |
| `[SAAT]` | Event time |
| `[MEKAN_ADI]` | Venue name |
| `[MEKAN_ADRESİ]` | Venue address |
| `[MEKAN_ŞEHİR]` | City |
| `[ANNE_BABA_1]` / `[SOYAD_1]` | Family names (side 1) |
| `[ANNE_BABA_2]` / `[SOYAD_2]` | Family names (side 2) |
| `[GOOGLE_FORM_LINKI]` | Google Form link for photo uploads |
| `[HARITA_LINKI]` | Google Maps search link |
| `[YÖN_TARİFİ_LINKI]` | Google Maps directions link |

## 📁 Replace Images

Put your own images in the `/img` folder:
- `heart.jpeg` — couple photo (shown as heart shape)
- `left_1.jpeg`, `left_2.jpeg`, `left_3.jpeg` — gallery photos
- `yakamoz.jpeg` — venue photo
- `dmn.mp3` — background music

## 🚀 Deploy with Firebase

```bash
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```
